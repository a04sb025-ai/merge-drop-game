# COSMO DROPS

小さな「星のタネ」を落とし、同じ星同士を合体させて全11段階の宇宙生命へ育てる、スマートフォン優先のオリジナル物理パズルです。

## 遊び方

- **指またはマウスで左右に動かし、離してドロップ**します。
- 同じ種類の星が接触すると、ひとつ上の星に進化します。
- 1回のドロップから合体が続くと CHAIN ボーナスが入ります。
- 赤い危険ラインを2.5秒以上越えるとゲームオーバーです。
- 最高段階の `Cosma` 同士は合体せず、盤面に残ります。

## 機能

- Canvasで描画する11段階のオリジナル星と、軽量な自前の円形剛体物理
- 合体パーティクル、波紋、浮遊スコア、控えめな画面振動
- Web Audio APIによる外部ファイル不要の効果音とサウンド切替
- NEXT、スコア、連鎖、最大到達星、`localStorage`保存のベストスコア
- 危険ラインの猶予判定、開始・一時停止・ゲームオーバー画面
- `visibilitychange`による自動停止、Pointer Eventsによるタッチ／マウス共通操作

物理ライブラリや画像・音声などの外部依存はありません。反復衝突解決、速度減衰、固定タイム上限、合体中フラグにより、モバイルでも安定するよう構成しています。

## 起動

静的ファイルのみなので、`index.html`を直接開くか、ローカルサーバーを起動します。

```bash
python3 -m http.server 8000
```

`http://localhost:8000/` を開いてください。すべて相対パスのため、GitHub Pagesのプロジェクトサイトでもそのまま動作します。
